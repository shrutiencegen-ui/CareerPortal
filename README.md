TalentBridge is a centralized platform designed to bridge the gap between Students, Companies It automates the recruitment workflow, from job posting to final selection.
 Tech Stack
Backend: Node.js, Express.js
Database: MySQL (Relational)
Security: JWT (JSON Web Tokens), Bcrypt.js (Password Hashing)
Architecture: MVC Pattern (Model-View-Controller)
Multi-Role Access Control: Separate logic and dashboards for Students, Companies, and Admins.
Secure Authentication: Registration and Login with encrypted passwords and token-based session management.
Job Lifecycle Management: Companies can post, update, and manage job listings.
Application Tracking System (ATS):
Students can apply and view their application history.
Companies can review applicants' profiles and update their status (Shortlisted, Selected, Rejected).
Relational Mapping: Complex SQL Joins to link student profiles, company details, and job applications.
